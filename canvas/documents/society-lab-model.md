# Society Lab · 社会模型假设说明

> 本文档说明模拟内核的数学假设。**所有关系都是可调整的模型假设，用于生成有趣的历史，不是适用于一切现实历史的普遍规律。** 参数集中于 `src/config.ts`，可在观察者面板查看变量实时值。

## 1. 单位与节奏

- 时间以**年**推进；人口单位为「人」；粮食单位为「人·年口粮」。
- 木材/石料/金属为抽象资源单位。
- 随机数由中央 `Rng`（mulberry32）驱动，种子化 + 状态保存 → 可复现；视觉随机独立，不污染模拟。

## 2. 人口（`sim/population.ts`）

```
出生率 = 0.032 × max(0.05, min(1.35, 粮食比)) × 住房因子 × (1 − unrest×0.25) × 健康因子
死亡率 = 0.017 × (1/健康) × (1 + 饥荒严重度×3.4 + unrest×0.25 + 拥挤惩罚)
健康   = 0.55 + 医道×0.055 + 水井0.08 + 公共堂×0.05 + 公共服务×0.12
```

- 粮食比 < 1 且粮储耗尽 → 饥荒严重度累积，死亡上升、外迁、 unrest 上升。
- 住房不足 → 出生率下降 + 拥挤死亡惩罚 + 触发分蘖迁徙（新营地）。
- 人口 < 12 → 聚落废弃（保留废墟视觉）。
- **假设**：原始社会出生率略高于死亡率（高波动）；医疗/公共服务单调改善健康。

## 3. 经济（`sim/economy.ts`）

```
劳动供给 = 人口 × (0.52 + 分工×0.25 上限)
农田产出 = 农田劳动 × 2.6 × (0.45 + 周边平均肥力×1.15) × 农耕技术系数 × 天气 × 祝福
采集产出 = 剩余劳动 × 1.35 × 野生丰度 × 天气
需求     = 人口 × (0.92 + 生活水平×0.22)
```

- 农业需要「农耕 ≥ 2 级」技术才会被建造 AI 采用（洪荒情景从采集开始）。
- 金属需要「工具 ≥ 2 级」（冶炼）。
- 粮仓有 4%/年腐败；饥荒按缺口比例计严重度。
- **假设**：产出的边际报酬由土地肥力约束（未建模资本深化）。

## 4. 技术（`sim/technology.ts`）

```
知识点/年 = 人口 × 0.02 × (0.5 + 教育) × (1 + 分工×0.6) × 稳定度 + 启蒙思潮×2.2
升级成本  = 8 × (等级−1)^1.55
```

八域：农耕/工具/营造/商贸/治理/医道/工业/文教。权重按当前社会需要分配（饥荒加权农耕、动荡加权治理、工业需工具4+营造3 解锁）。跨级产生「发明」事件。**假设**：知识是人口规模与教育的函数（规模效应）。

## 5. 制度与分配（`sim/institutions.ts`）

收入份额：
```
劳动份额 = 0.34 + 雇佣×0.36 + 合作×0.24 − 强制×0.30 − 依附×0.16 + 平民组织×0.05
国家份额 = 国家能力 × (0.1 + 公共服务×0.22)
精英份额 = 1 − 劳动 − 国家 （夹在 6%..68%）
财富份额每年向收入份额收敛 5.5%（资产增值偏向精英 ×1.18）
```

漂移（年）：
```
私有制  += 市场×0.006 + 土地集中×0.004 + 工业等级×0.006 …
强制劳动 += 战争记忆×0.02 − 国家能力×0.004 − 启蒙×0.004 …
依附劳动 += 土地集中×剩余×0.005 − 市场×0.004 − 工业×0.005 …
雇佣劳动 += 市场×0.006 + 工业×0.008 …
合作劳动 += 启蒙×0.006 + 教育×0.003 + 公有×0.004 …
```

**假设**：制度变迁是多个慢变量共同漂移的结果；单一变量不足以翻转形态。改革渠道（参与、组织）与压制（国家能力+精英组织）决定冲突走向。

## 6. 冲突（`sim/conflict.ts`）

```
unrest 目标 = 0.05 + 饥荒记忆 + 精英财富超额 + 土地集中超额 + 资源压力超额
             + 强制×0.3 + 依附×0.12 + 战争记忆×0.15 + (1−信任)×0.2
             − 参与×0.3 − 公共服务×0.35 − 教育×0.1
```

unrest > 0.52 时按张力概率触发集体行动，结局按条件权重选择：抗议 / 改革 / 镇压 / 暴动 / 革命 / 分立。**随机只影响时机与并列选项的抽取，不制造无因之火**；同一矛盾可有多条出路。

## 7. 形态识别（`sim/society.ts`）

```
原始   = 共有×0.9 + 无农业×0.35 + 无剩余×0.3 + (1−分工)×0.25 + 小规模
奴隶制 = 强制×1.55 + 剩余×0.18 + 国家能力×0.18 + 战争记忆×0.25 − 市场×0.25
封建   = 依附×1.25 + 土地集中×0.75 + 私有×0.2 + 农业×0.25 + (1−市场)×0.18 − 工业×0.22
资本主义 = 雇佣×1.15 + 市场×0.6 + 工业×0.32 + 私有×0.22 + 中产财富×0.12
社会主义 = (公有+合作)×1.05 + 公共服务×0.36 + 参与×0.26 + 教育×0.14
```

得分最高者为主形态；次高 ≥ 80% 时显示「混合倾向」。人口清零 → 文明废墟。
