# Society Lab · 视觉与资产规范

> 全部视觉资产为**程序化生成**（Canvas 2D 矢量绘制 + CSS 主题 + 内联 SVG 图标），无外部图片依赖，规避版权问题。

## 1. 总体风格

「精致的 2.5D 微缩沙盘 + 清晰易读的动态世界」：

- 等距投影：格 64×32px，海拔每级抬升 9px，形成立体沙盘感；侧壁用深土色。
- 桌台背景：深墨绿 `#20302c`，世界像放在实验室桌上的沙盘。
- 色彩：明亮、协调、低饱和自然色 + 少量高饱和点缀（金 `#c9a227`、青 `#2f7e76`）。

## 2. 地形色板（`render/terrain.ts`）

| 地形 | 顶面色 | 细节 |
| --- | --- | --- |
| 草原 | `rgb(138,176,106)` ±9% 7 变体 | 草斑 speckle |
| 沃土 | `rgb(190,168,92)` | 垄沟线条 |
| 森林 | 底 `rgb(104,142,92)` | 2~4 棵三层树（干+冠+高光），远缩略为椭圆 |
| 丘陵 | `rgb(168,172,122)` | 石斑 |
| 山地 | `rgb(141,133,120)` | 30~52px 山峰 + 雪顶 |
| 石地 | `rgb(156,150,140)` | 3 块碎石 + 矿脉金菱形 |
| 水域 | `rgb(84,156,196)` | 正弦波光动画、低于地面 5px |

每格颜色由确定性哈希抖动，避免单调网格感。领地边界 35% 透明墨绿描边。

## 3. 建筑视觉语言（`render/buildings.ts`）

五个时代色板（原始茅草 → 农业木瓦 → 城镇陶瓦 → 工业砖铁 → 现代水泥青），14 种建筑各有独立剪影：

- **营地**：双色帐篷 + 跳动篝火（3±1.4px 正弦）。
- **住宅**：木骨泥墙小屋/农舍/街屋（3 层）随时代升级，窗户暖黄。
- **农田**：褐色田垄 + 作物随 3 年周期生长（绿→金黄），椭圆株丛。
- **粮仓**：架高防潮 + 谷袋。**水井**：石圈 + A 架辘轳。
- **工坊/工厂**：烟囱 + 程序化炊烟（相位错开的三团上升渐隐）；工厂为锯齿屋顶双烟囱。
- **集市**：条纹雨棚（6 色条交替）。
- **公廨**：台基 + 柱体 + 波动旗帜。**墙垒**：城齿垛口。
- **合作社**：三圆环徽记。**公共堂**：生命树标识。
- 建造中：半透明幽灵体 + 脚手架线框。

## 4. 代表性居民（`render/villagers.ts`）

- 数量 = min(42, max(4, 人口×5.5%))，与模拟人口解耦。
- 五种角色配色：农（卡其）/ 工（蓝灰）/ 商（砖红）/ 贵（紫）/ 童（浅小）。
- 行为：POI（农田/井/集市/公廨/中心）间行走，速度 26–46px/s；行走上下弹跳 + 双腿交替；停留时劳作前倾摆动；30% 概率头顶搬运物资点。
- 载入即生成，纯视觉随机（不消耗模拟 RNG）。

## 5. 特效

- **雨**：区域内斜落雨丝 + 全屏冷色薄雾 + Web Audio 白噪声雨声（按影响格数渐入）。
- **旱**：暖橙菱形覆层 + 热浪曲线。
- **祝福**：金色粒子上旋（8 粒相位循环）。
- **事件 ping**：扩散椭圆环（2.2s 衰减）。
- **神力闪光**：全屏 0.28–0.35 alpha 色闪（指数衰减）。
- **农田作物**：3 年周期生长动画。

## 6. UI 主题

- 暖纸 `#f5efe3` × 墨 `#3b3128` × 青釉 `#2f7e76` × 金 `#c9a227`；危险 `#b4552d`。
- 深色 HUD 面板覆盖在世界上（rgba 28,38,34,0.92 + 毛玻璃）。
- 主界面 = 世界地图优先：顶栏仅年份/形态徽章/人口/粮食保障率 + 时间控制；高级数据全部收进观察者面板。
- 事件卡、编年史、观察者、存档为纸质模态；事件流在底部横向滚动。
- 图标：手绘线稿风 24×24 SVG（`ui/icons.ts`），事件类别有专属配色。
- 字体：系统中文栈（PingFang SC / Noto Sans SC / Microsoft YaHei）。

## 7. LOD 与性能

- 缩放 < 0.45 略树木/小人；< 0.55 略波光；< 0.6 略边界；< 0.7 略田垄细节。
- 视口裁剪（网格范围反算）+ y 排序绘制。
- 小地图 48×48 px 每像素一格，700ms 节流重绘，视口白框实时。
