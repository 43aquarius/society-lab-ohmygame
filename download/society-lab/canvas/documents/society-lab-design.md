# Society Lab《人类社会实验室》· 游戏设计文档

> 版本 1.0 · OhMyGame web-game 工程 · TypeScript + Canvas 2D（零运行时依赖）

## 1. 一句话定位

上帝视角的社会演化沙盒：玩家创造并干预一个 2.5D 微缩世界，社会按相互联系的规则自主发展，历史在玩家意料之外自然发生。它是一款游戏，不是社会科学数据可视化软件。

## 2. 体验目标

1. **好玩**：明确的操作（神力）、风险（饥荒/瘟疫/冲突）、选择（干预 or 旁观）与意料之外的结果（革命、分裂、倒退）。
2. **好看**：精致微缩沙盘、会动的居民、随时代生长的城市、直观的天气与神迹特效。
3. **可信**：人口、生产、所有制、分配、制度与冲突之间有可解释的因果链，事件不编造。
4. **耐玩**：种子复现、双情景、双神力模式、历史分支对照实验。

优先级：核心可玩性 > 视觉反馈 > 社会系统深度 > 实验工具。

## 3. 核心循环

```
创造世界（种子/规模/情景/模式）
  → 聚落采集/农耕（模拟按年推进）
  → 人口增长、建造、分工与财富分化
  → 制度漂移 → 冲突/改革/革命 → 社会形态变迁
  → 事件卡 + 编年史沉淀
  → 玩家神力干预（地形/天象/祝福/启蒙/思想）
  → 新的历史路径；存档 / 分支 / 重玩
```

即使不操作，世界也持续发展；干预后，变化立即可感知（地形变色、产出变化、事件卡、曲线）。

## 4. 系统架构

模拟内核与渲染完全解耦（`sim/` 不 import `render/`、`ui/`）：

| 模块 | 文件 | 职责 |
| --- | --- | --- |
| WorldGenerator | `src/worldgen.ts` | 种子化值噪声地形：山地/丘陵/河流/湖泊/沃土/森林/石地/矿脉 |
| WorldState | `src/types.ts` | 全部数据契约 + 中央 RNG |
| SimulationManager | `src/sim/manager.ts` | 年度编排：天气→技术→经济→人口→建造→制度→形态→冲突→事件→采样→快照 |
| PopulationSystem | `src/sim/population.ts` | 出生/死亡/饥荒/迁徙/分蘖新聚落 |
| EconomySystem | `src/sim/economy.ts` | 生产（劳动×土地×技术×天气×祝福）、消耗、资源、需求驱动建造 AI、阶段跃迁 |
| TechnologySystem | `src/sim/technology.ts` | 八域知识积累与发明叙事 |
| InstitutionSystem | `src/sim/institutions.ts` | 所有制/劳动关系/土地集中/财富分配/信任/参与的漂移 |
| SocietyClassifier | `src/sim/society.ts` | 五形态评分识别 + 混合形态 + 变迁叙事 |
| ConflictSystem | `src/sim/conflict.ts` | 紧张度→抗议/改革/镇压/暴动/革命/分立六种结局 |
| EventSystem | `src/sim/events.ts` | 条件触发 + 真实原因记录 + 状态回写 |
| GodPowerSystem | `src/powers.ts` | 9 种神力 + 净化响应 + 能量经济 |
| VisualWorld | `src/render/` | 等距渲染、摄像机、LOD 裁剪、小人、特效、小地图 |
| UIManager | `src/ui/` | HUD/工具栏/事件流/事件卡/编年史/观察者/存档 |
| HistoryManager | 编年史（chronicle + snapshots） | 带原因与结果的完整历史 |
| SaveManager | `src/saves.ts` | 版本化 JSON、6 槽位、自动存档、导入导出、分支快照 |
| AudioManager | `src/audio.ts` | Web Audio 全合成音效与环境 |

## 5. 神力系统（第一版 9 + 1）

| 分组 | 神力 | 效果 | 成本 |
| --- | --- | --- | --- |
| 造物 | 生长之林 | 森林铺展（木材/采集） | 6 |
| 造物 | 丰饶沃土 | 土地肥沃化 | 5 |
| 造物 | 涌泉之水 | 旱地出水 | 8 |
| 造物 | 大地之藏 | 埋下矿脉 | 10 |
| 天象 | 唤雨 | 区域 5 年多雨（产量+/视觉雨幕） | 6 |
| 天象 | 降旱 | 区域 4 年干旱（产量-/旱象） | 4 |
| 启蒙 | 丰产祝福 | 聚落 6 年收成 +40% | 12 |
| 启蒙 | 知识启蒙 | 知识点注入 + 启蒙思潮 | 10 |
| 启蒙 | 思想传播 | 参与/组织/平民思想提升 | 14 |
| 响应 | 净化疫病 | 终止进行中的疫情（事件卡触发） | 12 |

模式：**自由上帝**（无限）/ **有限干预**（能量 100，每年回 4）。所有神力直接修改模拟状态并记录为编年史「神迹」。

## 6. 事件系统

条件驱动（粮食保障率、人口密度、财富集中、技术跨级、阶段跃迁、资源压力……），触发后：
- 卡片显示**真实变量构成的原因**；
- 效果回写世界（人口、粮储、建筑、 unrest、市场…）；
- 编年史持久化（年份/地点/起因/结果/是否神迹）。

进行中事件（activeEvents）：疫病持续 3 年逐年减员，可被净化——展示"事件是过程而非字幕"。

## 7. 社会形态

评分制（非科技树解锁）：原始 / 奴隶制 / 封建 / 资本主义 / 社会主义 + 混合倾向显示。变迁需要变量跨阈值，且记录判定依据。战争俘虏推动强制劳动（奴隶制路径）；土地集中推动依附劳动（封建路径）；市场+工业推动雇佣（资本主义路径）；组织+思想+公共性推动合作与公有（社会主义路径）。没有必然路线。

## 8. 时间与存档

暂停/1×/2×/4×/单步；每 10 年自动存档；6 手动槽位；文件导入导出；每 25 年+形态变迁自动快照，可手动 pin，从任意带数据快照**创建平行分支**。

## 10. 已知限制

- 音效为合成音（无音频资产管线）；
- 事件文案为模板生成（未接 LLM 叙事）；
- 单文明（多聚落），无跨文明外交；
- 有限模式的神力能量 UI 在顶栏之外的左栏显示。
