# Society Lab《人类社会实验室》

> 上帝视角的社会演化沙盒 · OhMyGame web-game 工程 · TypeScript + Canvas 2D · **零运行时依赖**

创造一个世界，看文明生长、分化与变革——在关键的时刻，以神力改写历史的走向。

![Society Lab](docs/screenshot-world.png)

## 这是什么

一款融合上帝视角世界创造、文明演化、社会制度模拟、动态城市建设与历史叙事的单机沙盒游戏。玩家不是国王或总统，而是这个世界的神：可以观察文明按相互联系的规则自主发展，也可以通过改变地形、天象、资源、知识与思想来干预历史。

- **好玩**：神力操作、饥荒/瘟疫/战争风险、干预或旁观的选择、意料之外的结果（革命、分裂、倒退、复兴）。
- **好看**：微缩等距沙盘、会走的居民、随时代生长的城市、雨幕与神迹特效、编年史事件卡。
- **可信**：人口、生产、所有制、分配、制度与冲突之间有可解释的因果链；每个事件都记录真实模拟变量构成的起因。
- **耐玩**：种子复现实验、双初始情景、双神力模式、历史分支对照。

## 快速开始

需要 Node.js 20+。

```sh
npm install
npm run dev        # 打开 http://127.0.0.1:5183
```

或直接游玩已构建版本（无需安装）：

```sh
npm run build      # 输出到 dist/
npx vite preview   # 或用任意静态服务器服务 dist/ 目录
# 也可以直接用浏览器打开 dist/index.html
```

其他命令：

```sh
npm test           # 模拟内核回归测试（12 项）
npx tsc --noEmit   # 类型检查
```

### 社会如何演化

模拟完全由变量驱动（没有"年份到了就升级"的设定）：

- 采集 → 农耕：人口压力 + 农耕技术 ≥ 2 级（神力启蒙可加速）
- 战争俘虏 → 强制劳动上升 → **奴隶制**倾向（同时推高冲突风险）
- 土地集中 + 依附劳动 → **封建**倾向
- 市场发育 + 工业技术 → 雇佣劳动 → **资本主义**倾向
- 组织能力 + 思想传播 + 公共服务 → **社会主义**倾向
- 混合形态会显示"（某形态倾向）"；人口清零则成为**文明废墟**

不同的种子、地形、神力与随机事件组合会产生不同的历史路径。用存档面板的「分支节点」可以从任意里程碑创建平行世界，对照两条历史。

## 存档说明

- **自动存档**：每 10 年写入 localStorage（主菜单可继续）。
- **手动槽位**：6 个；存档面板（`S`）点击空槽即存，点「读取」载入。
- **文件**：支持导出 JSON / 导入。
- **历史分支**：每 25 年与形态变迁年自动记录快照；也可手动「在此记录分支节点」，从带 ◆ 标记的节点创建新分支（新随机流，避免重放分歧）。
- 存档版本 `society-lab-save-v1`，字段向后兼容。

| 模块 | 文件 | 职责 |
| --- | --- | --- |
| WorldGenerator | `src/worldgen.ts` | 种子化值噪声地形：山地/丘陵/河流/湖泊/沃土/森林/石地/矿脉 |
| SimulationManager | `src/sim/manager.ts` | 年度编排（天气→技术→经济→人口→建造→制度→形态→冲突→事件→快照） |

| EconomySystem | `src/sim/economy.ts` | 生产（劳动×土地×技术×天气×祝福）、消耗、资源、需求驱动建造 AI |
| TechnologySystem | `src/sim/technology.ts` | 八域知识积累与发明叙事 |
| InstitutionSystem | `src/sim/institutions.ts` | 所有制/劳动关系/土地集中/财富分配/信任漂移 |
| SocietyClassifier | `src/sim/society.ts` | 五形态评分 + 混合 + 变迁判定依据 |
| ConflictSystem | `src/sim/conflict.ts` | 紧张度 → 抗议/改革/镇压/暴动/革命/分立 |
| EventSystem | `src/sim/events.ts` | 条件触发 + 真实原因记录 + 状态回写 |
| GodPowerSystem | `src/powers.ts` | 9+1 种神力与能量经济 |
| VisualWorld | `src/render/` | 等距渲染、摄像机、LOD、居民、特效、小地图 |
| UIManager | `src/ui/` | HUD/事件卡/编年史/观察者/存档面板 |

模型假设详见 `canvas/documents/society-lab-model.md`。

## 测试与验证

- `npm test`：12 项模拟内核回归——种子确定性、世界生成合法性、五形态识别、饥荒触发、强制劳动→精英份额、神力实效、存档往返、长程 200 年不崩溃、形态变迁记录判定依据。
- 无头浏览器实测（Chromium）：主菜单建图 → 摄像机 → 神力 → 事件卡 → 编年史 → 观察者 → 存读档往返 → 61 FPS。开发模式暴露 `window.__OHMYGAME_PLAYTEST__`（snapshot/setSeed/step/usePower/serialize/loadSave）供自动化验证，生产构建不含。

## 已知限制

- 单文明（多聚落），无跨文明外交/贸易网络模拟。
- 事件文案为结构化模板生成，未接入 LLM 叙事。
- 音效为程序合成，音色简单。
- 从自然演化观察到奴隶制/封建路径需要较长游戏内时间（数百模拟年），或通过干旱制造资源压力触发战争路径；资本主义/社会主义路径在正常游玩节奏（约 200–300 年）可自然达到。
